CarbonLog – annotated wireframes

Low-fidelity screens of the CarbonLog app as it is implemented in public/carbonlog.html. Numbers mark controls and states; each note names the requirement from docs/business-case.md (R1–R14) and the API call behind it.

W0Navigation and flow

One page with three tabs. Adding and editing happen in a dialog, so the user never loses the list. Every action calls the REST API and then refreshes what is on screen.
